# ViooClient

ViooClient is a comprehensive client-side Minecraft mod designed for Minecraft Java Edition 1.21.11, built using the Fabric mod loader. It offers a wide range of features to enhance your gameplay experience, including GPS navigation, visual enhancements, ESP (Extra Sensory Perception) tools, and a customizable HUD (Heads-Up Display). The mod features a dark GUI with purple accents, inspired by Pulse Visual, with smooth animations and configurable settings. Open the GUI with the Right Shift key.

## Install

1. Download the latest version of ViooClient from the [GitHub releases page](https://github.com/enderdevelopment/viooclient/releases).
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded.

## Use

1. Launch Minecraft and load a world.
2. Press the Right Shift key to open the ViooClient GUI.
3. Navigate through the two-column interface to access different categories and features.
4. Use the search function to quickly find specific modules.
5. Customize the settings and keybinds as needed.
6. Enjoy the enhanced features and functionalities provided by ViooClient.
